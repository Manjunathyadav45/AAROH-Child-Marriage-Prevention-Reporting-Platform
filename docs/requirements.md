# AAROH - Project Requirements

## 1. Project Overview
AAROH is a child marriage prevention and reporting platform.

## 2. Main Users
- General public
- Authorised reviewers
- Administrators

## 3. Main Features

### Reporting
- Submit suspected child marriage reports.
- Allow confidential reporting.
- Generate a unique report ID.
- Allow approximate location details.

### AI Assistance
- Classify incoming reports.
- Help prioritise reports.
- Display classification confidence.
- Allow human verification.

### Admin Dashboard
- View submitted reports.
- Review report details.
- Update report status.
- Manage authorised users.

### Case Tracking
- Track report progress.
- Maintain activity history.
- Record authorised actions.

## 4. Privacy and Security
- Protect reporter identity.
- Restrict access to sensitive information.
- Never expose children's personal details publicly.
- Use secure authentication.

## 5. Expected Result
A secure and accessible platform that supports child marriage prevention through reporting, review and intervention.
