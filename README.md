# AAROH
## Child Marriage Prevention and Reporting Platform

### About the Project
AAROH is a technology-based platform designed to help prevent child marriages through confidential reporting, AI-assisted report classification and authorised intervention.

### Main Objectives
- Provide a confidential reporting system.
- Help authorised personnel review reports.
- Use AI to assist in report classification.
- Track report verification and intervention.
- Support child protection and prevention.

### Technologies
- Frontend: React
- Backend: Python FastAPI
- Database: PostgreSQL
- Machine Learning: Python and Scikit-learn

### Project Status
Planning and initial development.
